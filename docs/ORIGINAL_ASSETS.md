# Original public example assets

COMMONPLACE is a fictional personal inspiration library created specifically for this open-source package. Created with the built-in imagegen tool; both outputs were visually inspected. They are concepts, not functional application screenshots.

## Editorial concept

Saved as examples/media/commonplace-editorial.png.

```text
Use case: ui-mockup. Asset type: original public open-source workflow example, full desktop app screenshot, wide 16:10.
Design a completely original high-end personal inspiration library called "COMMONPLACE". This is a fictional example for teaching reference-driven frontend design, not an AI workspace. Bold editorial asymmetrical layout on warm ivory, enormous black serif title "Make room for ideas.", a small coral accent slash, compact left navigation Library / Collections / Discover, beautifully typeset real UI text. Main area shows a tactile floating sculptural folded coral ribbon and cobalt-blue glass sphere arranged among a curated masonry collection of three art/design references as abstract ORIGINAL geometric artworks, no borrowed artworks. Upper nav COMMONPLACE with small save button, toolbar All ideas / Objects / Spaces / Typography, clear sort menu. Right slim inspector titled "Selected idea", with material swatches coral, cobalt, cream and a "Save to collection" button. Bottom subtle collection strip "Weekend discoveries" and "12 ideas". Strong hierarchy, art direction and color contrast, clear readable functional control labels, spacious layout with areas for dense catalog data; exceptional editorial typography, believable 3D translucent material, soft daylight shadows, grain-free high quality. No dashboard metric cards, no knowledge pavilion, no copied creator logos, no device frame, no watermark. Render one complete app screenshot, edges intact.
```

## Spatial concept

Saved as examples/media/commonplace-spatial.png.

```text
Use case: ui-mockup. Asset type: full desktop screenshot of an original fictional inspiration library, 16:10, no device frame. Brand "COMMONPLACE". Produce a structurally different SPATIAL CANVAS interface, not a dashboard and not editorial masonry. Inky warm plum backdrop with luminous coral, apricot, cobalt, cream; one very refined, airy curving ribbon of frosted coral resin sweeping through the middle above 3 little abstract cobalt glass sculptures, torus and orange stone blocks, on an open seamless studio floor, no architecture or pavilion. Large code-like but readable UI labels: top header COMMONPLACE / Your collection / 12 ideas. Left floating narrow translucent tool palette "Objects" with three small items Fold / Orbit / Balance. Upper center pill Library / Canvas / Focus with Canvas active. Right floating calm paper panel "Balance in motion", readable object metadata, "Save idea" button. Bottom slim native-looking filmstrip of six saved idea tiles "Weekend discoveries", small view controls "Reset view" "Top view". Strong tactile depth, carefully composed realistic material, crisp restrained windows that do not obscure the central sculpture, beautiful conceptual art direction, original props; clear visual hierarchy and generous open space. Every object is original abstraction, no borrowed art, no private-project content, no AI workspace, no knowledge library pavilion, no logos of real creators, no watermark. One coherent app UI image.
```

The independent sculpture in demo/sculpture.js uses procedural geometry, with no imported models, textures or creator footage. Original audio is synthesized by scripts/make-sound.py.
